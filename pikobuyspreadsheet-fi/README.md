# PikoBuy Spreadsheet Finland

Astro static site. In this folder, run `npm ci` and `npm run build`; the output is `dist/`. The build generates category and product pages and a sitemap.

The production domain is https://pikobuyspreadsheet.fi. Product data is a snapshot from 19 October 2026. QC photos are not included in the export and are not live. Review data completeness, image search, buying links and translations before assuming these are complete or current.
